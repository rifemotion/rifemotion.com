# Пошаговое руководство по переносу rifemotion.com на VPS

В этом руководстве описан весь процесс: от аренды сервера и перенаправления домена с GitHub Pages до запуска Python-сервера с 2FA и получения SSL (HTTPS).

---

## Шаг 1. Аренда виртуального сервера (VPS)

Для работы сайта с Python-сервером и видеофоном подойдет любой стандартный VPS:
- **Характеристики**: от 1 CPU, 1–2 GB RAM, 15–25 GB SSD (этого хватит с запасом).
- **ОС**: **Ubuntu 22.04 LTS** или **Ubuntu 24.04 LTS** (64-bit).
- **Провайдеры**: Timeweb Cloud, Beget, Hetzner, Selectel, Aeza, DigitalOcean и др.

После создания сервера вам выдадут:
- **IP-адрес** сервера (например: `194.87.123.45`)
- Логин: `root`
- Пароль или SSH-ключ для входа.

---

## Шаг 2. Настройка DNS для домена `rifemotion.com`

Сейчас ваш домен направлен на серверы GitHub Pages. Нужно перенаправить его на ваш новый IP-адрес:

1. Откройте панель управления, где вы покупали домен (Reg.ru, Namecheap, Cloudflare, Beget и т.д.).
2. Перейдите в раздел **Управление DNS-зоной** (DNS Records).
3. **Удалите старые записи**, связанные с GitHub Pages (IP `185.199.108.153`, `185.199.109.153` или CNAME `*.github.io`).
4. **Добавьте новые A-записи**:
   - **Имя / Host**: `@` (или оставить пустым/имя домена)  
     **Тип**: `A`  
     **Значение / IP**: `<IP_ВАШЕГО_СЕРВЕРА>`  
     **TTL**: `Auto` или `300` / `3600`
   - **Имя / Host**: `www`  
     **Тип**: `A`  
     **Значение / IP**: `<IP_ВАШЕГО_СЕРВЕРА>`

*(Обновление DNS по всему миру обычно занимает от 10 минут до 2 часов).*

## Шаг 3. Загрузка проекта на VPS

Подключитесь к вашему серверу через терминал (PowerShell / Termius / PuTTY):
```bash
ssh root@<IP_ВАШЕГО_СЕРВЕРА>
```

### Вариант А: Через Git (Рекомендуется)
Если проект на GitHub:
```bash
mkdir -p /var/www
cd /var/www
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> rifemotion
cd rifemotion
```

### Вариант Б: Через SCP / SFTP (FileZilla)
Или скопируйте файлы из вашей локальной папки на сервер в директорию `/var/www/rifemotion/`.

---

## Шаг 4. Автоматическая установка и запуск

Перейдите в папку проекта и запустите подготовленный скрипт автоустановки:

```bash
cd /var/www/rifemotion
chmod +x deploy/setup_server.sh
./deploy/setup_server.sh
```

Этот скрипт автоматически:
1. Установит Python, Nginx, Certbot и UFW Firewall.
2. Создаст виртуальное окружение `venv` и установит библиотеки (`fastapi`, `uvicorn`, `pyotp`, `qrcode` и др.).
3. Сгенерирует безопасный ключ `.env`.
4. Настроит и запустит фоновую службу `systemd` (`rifemotion.service`), которая будет автоматически перезапускать сервер при сбоях и перезагрузке VPS.
5. Настроит Nginx для мгновенной отдачи видео и статики и проксирования запросов к Python.

---

## Шаг 5. Создание администратора и первый вход с 2FA

1. На сервере выполните команду:
   ```bash
   /var/www/rifemotion/venv/bin/python create_admin.py
   ```
2. Введите имя пользователя (например, `admin`) и надежный пароль.
3. Откройте в браузере: `http://rifemotion.com/admin/login` (или `http://<IP_СЕРВЕРА>/admin/login`).
4. Введите логин и пароль.
5. Сервер покажет страницу **Настройка 2FA с QR-кодом**.
6. Откройте на телефоне приложение аутентификатора (**Google Authenticator**, **Яндекс Ключ**, **Apple Пароли** или **1Password**) и отсканируйте QR-код.
7. Введите 6-значный сгенерированный код и нажмите **«Активировать 2FA и войти»**.
8. Вы попадете в защищенный дашборд администратора с сообщением **Hello World**!

---

## Шаг 6. Включение бесплатного SSL-сертификата (HTTPS)

Как только DNS-записи домена обновятся, выполните на сервере одну команду:

```bash
certbot --nginx -d rifemotion.com -d www.rifemotion.com
```

- Укажите ваш email для уведомлений.
- Согласитесь с условиями (нажмите `Y`).
- Certbot автоматически установит SSL-сертификат и настроит вечное автоматическое продление!

Теперь сайт и панель администрирования будут работать по защищенному протоколу:
- Сайт: **`https://rifemotion.com`**
- Админка: **`https://rifemotion.com/admin`**

## Полезные команды для управления сервером

- **Статус сервера**:
  ```bash
  systemctl status rifemotion
  ```
- **Перезапуск приложения (после правок кода)**:
  ```bash
  systemctl restart rifemotion
  ```
- **Просмотр логов в реальном времени**:
  ```bash
  journalctl -u rifemotion -f
  ```
- **Сброс пароля или сброс 2FA админа**:
  ```bash
  /var/www/rifemotion/venv/bin/python create_admin.py --reset-2fa
  ```
